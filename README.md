# GoFit (thesis snapshot)

An early snapshot (May 2026) of the gym membership gamification app built for my final-year thesis at Universitas Multimedia Nusantara.

**Active development continues in [brianrickyb/gofit-gamification](https://github.com/brianrickyb/gofit-gamification)** ([live demo](https://gofit-gamification.vercel.app/)), which adds Firebase-backed real-time progress, the auth context, expanded challenges, and many fixes since this snapshot.

This repository is kept for reference only.
